Show the shape of the answer you need

Carlsson & Co. · As of November 2026

A useful answer should fit where you will use it. Learn to name the fields, show a small example and say how to handle an empty value. These exercises go beyond asking for a table: they make the shape something you can check.

ChatGPT: make a table you can paste into a tracker

  • Task: Extract actions from short notes.
  • Context: The tracker has three fixed columns.
  • Output: One row per action, using the supplied column names.
  • Boundaries: The sample row shows the format only; it is not an action to include.

Weak prompt

Organise these notes: Jo will check the slides on Tuesday. Pat will book the room; no date agreed.

Improved prompt

Turn these notes into a Markdown table for my tracker: Jo will check the slides on Tuesday. Pat will book the room; no date agreed. Use exactly these columns: Action | Owner | Due. Format example only: Check notes | Alex | Monday. Do not include the example row. Use “Not confirmed” for a missing date. Return only the table; preserve the supplied names and weekday.

Worked example

Illustrative answer, written for this lesson:

ActionOwnerDue
Check slidesJoTuesday
Book roomPatNot confirmed

Exercise

Add a third fictional action with no owner. Specify the marker for a missing owner, then check the returned table before pasting it into a tracker.

Checklist

Claude: repeat a short entry format

  • Task: Turn workshop notes into two catalogue entries.
  • Context: Readers need the same fields in the same order to compare sessions.
  • Output: A title, duration and preparation line for each session.
  • Boundaries: Separate the example from the facts; do not copy its content.

Weak prompt

Tidy these workshop notes: Sketching, 30 minutes, bring paper. Listening, 20 minutes, no preparation.

Improved prompt

Write two workshop entries for a noticeboard. Use the same three labelled lines for each so readers can compare them. <example>Title: Folding
Duration: 15 minutes
Preparation: Bring one sheet</example> This example shows format only. <facts>Sketching: 30 minutes, bring paper. Listening: 20 minutes, no preparation.</facts> Return only the two entries, separated by a blank line. Keep the facts unchanged and add no promotional claims.

Worked example

Illustrative answer:

Title: Sketching
Duration: 30 minutes
Preparation: Bring paper

Title: Listening
Duration: 20 minutes
Preparation: None

Exercise

Write a format example with one additional field. Supply that field for one fictional session and mark it unknown for the other. Check that the format stays consistent.

Checklist

Codex: define a tiny CSV export

  • Task: Create a small export in a disposable practice project.
  • Context: A downstream tool expects a header and two columns.
  • Output: One CSV file with an exact, supplied example.
  • Boundaries: Write only the named file; do not install or publish anything.

Weak prompt

Make an export of these durations: Read 10, Write 25.

Improved prompt

In this disposable practice project, create only durations.csv. It must be UTF-8 CSV with the header task,minutes and the rows Read,10 and Write,25, in that order. Format example for the header and first row: task,minutes
Read,10. Do not duplicate that example row. Check that there are exactly two data rows and their minutes total 35. Report the file and the checks actually run. Do not install dependencies, commit, push or deploy.

Worked example

Illustrative file content:

task,minutes
Read,10
Write,25

The two durations total 35 minutes. The file content illustrates the target; it is not evidence that an assistant created or checked a file.

Exercise

Try the prompt in a disposable folder. Open the file in a text editor and check the header, row count and total yourself.

Checklist

Reuse the structure

Turn [material] into [format]. Use these fields in this order: [fields]. Format example only: [example]. Do not include example data. Represent missing values as [marker]. Check [shape and facts].

Check the content as well as the layout. A neat table can still contain a wrong fact.
