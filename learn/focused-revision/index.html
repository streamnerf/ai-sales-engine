Improve an answer with one focused follow-up

Carlsson & Co. · As of November 2026

When an answer is close, name the part to change and the parts to preserve. This lesson turns “make it better” into a small revision you can judge: one target, a boundary and a check. Use fictional drafts and disposable code while you practise.

ChatGPT: make the opening useful

  • Task: Revise only the opening of an internal notice.
  • Context: The current opening delays the main point.
  • Output: The full notice with a direct first sentence.
  • Boundaries: Preserve the confirmed time and remaining sentences.

Weak prompt

Make this better: We have an update to share. The library room closes at 16:00 on Friday. Return keys to reception.

Improved prompt

Revise the notice from your previous answer: “We have an update to share. The library room closes at 16:00 on Friday. Return keys to reception.” Replace only the first sentence so the closure is clear immediately. Keep the other two sentences exactly as written and add no reason for the closure. Return the full notice. Check that Friday and 16:00 are unchanged.

Worked example

Illustrative revision:

Please plan for the library room closure. The library room closes at 16:00 on Friday. Return keys to reception.

Exercise

Use the quoted notice as a fictional first draft in a chat. Try the weak follow-up, then the focused one. Compare how much unrelated text changed.

Checklist

Claude: replace vague actions with concrete ones

  • Task: Revise two vague action labels.
  • Context: A colleague needs to know what to do next.
  • Output: The same table with only the action cells changed.
  • Boundaries: Preserve owners and deadlines; use the supplied clarification.

Weak prompt

Improve your action table: Slides | Jo | Tuesday; Room | Pat | Friday.

Improved prompt

<previous_table>Action | Owner | Due
Slides | Jo | Tuesday
Room | Pat | Friday</previous_table> Revise only the Action cells. Clarification: Jo needs to check the slide titles; Pat needs to confirm the room booking. Return the full table with the same columns and row order. Keep owners and deadlines unchanged. Check that each action starts with a verb. This will help the next colleague act without reading our chat.

Worked example

Illustrative revision:

ActionOwnerDue
Check slide titlesJoTuesday
Confirm room bookingPatFriday

Exercise

Add one fictional row whose intended action is unclear. Ask Claude to flag that row for clarification while revising the two actions it can support.

Checklist

Codex: revise one behavior and preserve the rest

  • Task: Handle empty input in a practice function.
  • Context: The first version already works for non-empty lists.
  • Output: A small patch and results for two specified cases.
  • Boundaries: Keep the function name and non-empty behavior.

Weak prompt

Improve the function you just wrote.

Improved prompt

Revise your previous average_minutes(values) function in stats.py in this disposable practice project. It currently returns sum(values) / len(values). Change only the empty-list behavior: return None for []. Preserve the function name and arithmetic mean for non-empty lists of non-negative integers. Change only stats.py. Check [] returns None and [10, 20] returns 15.0; report actual results and any check you could not run. Do not install dependencies, commit, push or deploy.

Worked example

Illustrative revision, not a recorded tool result:

def average_minutes(values):
    if not values:
        return None
    return sum(values) / len(values)

The empty list takes the first branch. For [10, 20], 30 divided by 2 remains 15.0. Review the diff as well as the outputs to confirm the change stayed within scope.

Exercise

Create the initial function in a disposable project. Request the focused revision, inspect the diff and run the two cases yourself. Compare the report with what actually happened.

Checklist

Reuse the structure

Revise [specific part] of the previous answer to [one observable change]. Preserve [facts or behavior]. Return [complete result or patch]. Check [criterion].

If the revision misses the target, point to the specific mismatch. Review preserved facts as carefully as the changed part.
