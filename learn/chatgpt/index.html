How to prompt ChatGPT

ChatGPT understands plain English, so you don't need a special formula. A short prompt is often enough. For work that matters, say what you want, give the context that changes the result, and add a boundary or two. Here is how OpenAI's official guide puts it, and how to use it for everyday work.

How ChatGPT reads a prompt

  • Start in your own words. You don't need technical syntax or a rigid formula. OpenAI's guide says to start in your own words, review the response, and use follow-up messages to shape the result. A short prompt is often enough.
  • Goal, context, output, boundaries. For larger or more important tasks, include the parts that matter: the goal (what ChatGPT should do), the context (information or sources that will help), the output (format, length or level of detail), and the boundaries (what must stay unchanged, and what it should check with you first). Use only the parts that help.
  • Start with the result. Start with the result you need, not a detailed list of steps. Include the audience or the format when those details change what ChatGPT should produce. Leave it room to search, compare and adjust, unless the process itself matters.
  • Add the context that changes the answer. Share the information that could change the result, and say what ChatGPT should take from each source. Attach files when you want it to summarise or compare them. If an image matters, point out the area to look at. When the answer depends on current information, ask it to use web search and to give sources you can check.
  • A boundary or two, not a rulebook. Boundaries are the few instructions that stop ChatGPT from creating extra work or taking an action you didn't intend. One or two is enough, for example: "Use only the supplied sources. Flag missing information instead of guessing," or "Prepare the message as a draft. Don't send it."
  • Say how you'll use the result. Tell ChatGPT how you plan to use the result, so it can choose the length, detail and layout. As of November 2026, current models tend to be more concise and direct, so say so if you want a longer or more formal answer. For important work, ask for a final check, then review the result yourself before you use it.
  • Improve it with a follow-up. Your first prompt doesn't need to be perfect. Review the result, then ask for the specific change you want: a more direct opening, a missing source, another option, or a different level of detail. You don't have to start over.
  • Standing rules live in Settings. Put preferences that should apply across chats in Settings, then Personalization, as custom instructions. Keep details that matter only to the current chat in the prompt.

A structure that works

You don't need every part every time. For a quick question, one clear sentence is enough. For work that matters, this shape covers what OpenAI's guide recommends: a goal, the context, the output you need, a boundary or two, and a final check. If you use ChatGPT Work for a larger task, add the audience and ask it to check the work before it finishes — and to wait for your approval before it sends or publishes anything.

Goal: [what should ChatGPT do]

Context: [who this is for, and the facts, files or sources that change the result]

Output: [format, length, and how I will use it]

Boundaries: [what must stay unchanged, and what to check with me first]

Before you finish, [the check I want, e.g. every next step has an owner].

Six prompts to copy

Replace the [brackets] with your own details. Each prompt shows one of the ideas above.

Reply to an unhappy customer

Goal, context, a clear output, and a boundary that nothing gets sent.

Goal: Write a reply to this unhappy customer.

Context: I run a small online shop. Here is their email:
[paste the customer's email]
Here is what happened, and what we can offer: [refund, replacement or the facts]

Output: A reply they can read on a phone, under 150 words. Apologise once, explain in plain words and offer the fix.

Boundaries: Use only the facts above. Don't promise anything else. Prepare the message as a draft. Don't send it.

Before you finish, check that every offer in the reply appears in the facts above.

A one-page update from meeting notes

Start with the result, and say how it will be used.

Goal: Turn these meeting notes into a one-page update a director can scan before Monday's meeting.

Context:
[paste the notes]

Output: Put the decisions and next steps first. Then a short summary of progress, risks, owners and due dates.

Boundaries: Keep approved dates and budget figures unchanged. Flag any conflicting or missing information.

Before you finish, check that every next step has an owner and a due date.

Product descriptions from the facts you have

Say the format, and limit ChatGPT to the facts you supply.

Goal: Write a product description for each item below.

Context: They will appear on my shop website. A first-time visitor should understand what the product is for within two sentences.
Products:
[name and three facts for each]

Output: About 100 words each, in a calm, plain voice. No superlatives.

Boundaries: Use only the facts given. Don't invent materials, sizes or shipping times.

Before you finish, list any fact you needed but didn't have.

A planned versus actual spending table

Tell it the output shape, and a boundary on the numbers.

Goal: Create a clear table of planned versus actual spending for this month.

Context:
[paste the planned amounts and the actual amounts, without personal account numbers]

Output: A simple table, then two sentences on any difference over 10%.

Boundaries: Keep the figures unchanged. If a number is missing, flag it instead of guessing.

Before you finish, check that the totals add up.

Research a decision, with sources

Ask it to search, and to show where each figure came from.

Goal: Help me choose a customer-support tool for a 10-person shop.

Context: We need email and a shared inbox, and we want to stay within [budget] a month.

Output: A short recommendation, then a table that compares three options on price, setup time and the features we need. Use web search for current information and include a link for each figure.

Boundaries: Distinguish reported facts from your analysis. Flag anything you couldn't verify.

Before you finish, list the two questions I should answer before I sign anything.

Rewrite a first draft

Name the change you want. The first prompt doesn't have to be perfect.

Goal: Rewrite this About page so a first-time visitor understands what I sell within two sentences.

Context:
[paste your About page]

Output: The full rewritten text in short, flowing paragraphs, then a short list of what you changed.

Boundaries: Keep every fact and price exactly as it is. Don't add claims I didn't write.

Before you finish, check that a stranger would know what I sell by the second sentence.
