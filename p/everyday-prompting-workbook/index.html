A practice workbook for beginners using ChatGPT, Claude or Codex-style briefs. Start with one small task

Fill in task, context, output and boundaries. Compare a weak request with a clearer brief using the same source material. Check the answer, request one change, and record what changed.

Each exercise includes a reusable template, a weak prompt, a filled improved prompt, an illustrative worked example, a review checklist and a follow-up exercise. The examples are editorial illustrations, not recorded model responses.

The 15 exercises

  • Practice 1: Plan a short work session — Preserve estimates before filling a schedule.
  • Practice 2: Summarize rough notes — Separate compression from interpretation.
  • Practice 3: Clarify a handover — Keep unknown ownership visible.
  • Practice 4: Rewrite for a reader — Change expression while preserving meaning.
  • Practice 5: Extract actions from a meeting — Distinguish decisions from suggestions.
  • Practice 6: Compare options against criteria — Make the basis of a comparison inspectable.
  • Practice 7: Break a task into steps — Define the finish before making a checklist.
  • Practice 8: Explain an unfamiliar term — Control depth and make limits visible.
  • Practice 9: Build a reading checklist — Turn supplied requirements into observable checks.
  • Practice 10: Convert notes into a table — Preserve missing values during formatting.
  • Practice 11: Check a draft against a brief — Ask for evidence before a verdict.
  • Practice 12: Ask useful clarifying questions — Identify the smallest missing decision.
  • Practice 13: Revise one thing at a time — Keep a revision attributable to one instruction.
  • Practice 14: Correct a small function with Codex — Name the file scope and checks.
  • Practice 15: Request a code review before changes — Separate diagnosis from permission to edit.

Also included: a reusable blank brief and a page for recording evidence and changes between attempts.

Sample reusable briefs

Replace the bracketed fields with your own facts.

Practice 1: Plan a short work session

Task: Plan a short work session for [purpose]. Context: [time window], [tasks and durations], [priority]. Output: A timed table and deferred work. Boundaries: Keep durations unchanged; do not split tasks without asking. Before finalizing, check [observable success criteria] and flag anything you cannot verify.

Practice 2: Summarize rough notes

Task: Summarize rough notes for [purpose]. Context: [notes], [reader], [maximum length]. Output: Three bullets plus unresolved questions. Boundaries: Use only the notes; preserve uncertainty and do not add causes. Before finalizing, check [observable success criteria] and flag anything you cannot verify.

Before you begin

Choose exercises relevant to your work. Everyday practice uses ChatGPT or Claude; the last two exercises introduce Codex-style file scope and verification in a disposable project. Coding is optional. Tool access and subscriptions are not included, and features vary by tool.

Use fictional or redacted material. Check facts and calculations yourself before using an answer. Clear instructions do not guarantee a correct response.
